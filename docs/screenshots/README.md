# Application Screenshots

Place your 2-3 screenshot images here:

1. `dashboard.png` - Main dashboard overview with balance summary and form.
2. `transactions_chart.png` - Spending breakdown chart and filtered transaction list.
3. `budget_alert.png` - Budget limit warning alert or mobile view screenshot.

Supported formats: `.png`, `.jpg`, `.jpeg`.
The main `README.md` in the project root is configured to automatically display these images once saved here!
